These are **unrun prototype acceptance gates**, not measurements. Save serials/revisions, firmware hashes, host OS, scope traces and current logs with the board revision. A passing UF2 or simulation is insufficient to release the electronics.

| Gate | Stimulus and observations | Acceptance |
| --- | --- | --- |
| Cold electrical safety | Disconnect battery. Use current-limited USB/3.3 V per hardware bring-up. Check ground, 3.3 V, switched rail, and DAT/CLK/RST/EN with pointer initially absent. Inspect pad numbering; D13 is P1.01, not charger P0.13. | Correct polarity/levels; no bridge, overheating, UICR or battery ADC conflict. Plug in only the confirmed 3.3 V SK8707-01-004 variant. |
| Charge selector | Measure charging first with suitable protected test fixture/emulator, including reset, DFU, boot, idle, sleep, USB insert/remove and disconnect switch positions. Validate P0.13 high impedance electrically, not only in DTS. | Normal charge near the intended low setting; worst applied charge and termination below selected pack limits, including tolerances. USB never implies battery disconnect by itself. |
| Pointer rail sequence | Scope TP_EN, switched 3.3 V, RST, CLK, DAT on cold boot and each wake; check open-drain low and released high, rise time and voltage. Observe fresh BAT 0xAA, ID 0x00 and enable-reporting ACK. Disconnect/reconnect a sensor with power removed only. | No backfeed with rail off; voltage/ramp and reset present with supported timing; consistent init and correctly signed X/Y. Repeated retries, stuck bus, false clicks or jumps are failures. |
| Matrix/HID | Exercise all 45 inputs on USB and BLE, verify left/right thumbs, Bluetooth profiles, F/J taps and opposite-hand GUI holds, navigation/numeric layers. Use at least a four-key cross-half chord. | Physical legends and controls agree with the spreadsheet/geometry. No ghosting, phantom clicks or unintended GUI when touching a mouse switch. |
| Composite mouse | Hold left click and move stick in all quadrants, then release; repeat with right click. Hold scroll and move diagonally in both directions. Release scroll while moving. Repeat with Raise and Lower. | Continuous drag, no host click while scrolling, horizontal/vertical wheel on correct axes, immediate return to cursor. Test selected USB/BLE hosts. |
| Connection faults | While dragging and separately while scrolling, power off only the left half; repeat with host unpair/reconnect and a right reset. Stress typing and diagonal pointing under closed-case split radio load. | Host eventually receives button-up and layer returns to base; reconnect is clean, no latent press or accidental click; record worst latency and any lost reports. Confirm both battery services. |
| Sleep and transport | Unplug USB on both. After 15 min idle, inspect gated pointer rail/current. Wake right then left; check first usable key and pointer. Hold a left mouse switch over the timeout; try sleep when USB remains attached. Run at least 30 cycles. | Rail really off in system-off and no PS/2 backfeed; no sleep during sustained hold/drag; clean re-init and no stuck button. Record whether the wake key is consumed and time to first correct motion. |
| Runtime | Measure total cell current per hand with USB removed in typing, sustained pointer, connected-idle, supervisor/reconnect and system-off states. Note Z-Tap setting separately from host event suppression, regulator/flash leakage and sample cell capacity. | Compare independently against the actual daily duty cycle and project target. Do not substitute sensor-only datasheet current for total system current. |
