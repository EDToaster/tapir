# Working in this repo

This repo holds several keyboard projects, each in its own folder with its own `AGENTS.md`. Read the project's file before working in it, and keep changes inside that project's folder unless they are shared.

- **Stop before ordering PCBs, PCBA, printed parts or components.** Paid fabrication and purchases need the owner's explicit approval.
- Design, simulate, render and revise in Git without asking about each trace, hole or case iteration.
- Paths in each project are relative to that project's folder. Moving a project folder must keep its internal paths intact.
